# 郭小猪 · Codex 桌宠

可以在工作的时候陪你的郭小猪。这个仓库包含 Codex 自定义宠物安装文件和一个睡觉动作预览。

![郭小猪待机预览](sleep-preview.gif)

## 下载和安装

1. 在 GitHub 页面点击 **Code → Download ZIP** 并解压。
2. 将解压出来的 `xionger-sleep-v2` 文件夹完整复制到：
   - Windows：`%USERPROFILE%\.codex\pets\`
   - macOS / Linux：`~/.codex/pets/`
3. 确认该文件夹里直接包含 `pet.json` 和 `spritesheet.webp`。
4. 打开 Codex 的宠物设置，刷新列表并选择 **郭小猪**。如果没有出现，重新打开应用后再检查。

## 动作

- 待机：睡觉。
- 处理中：大笑。
- 完成并有未读结果：撒花。
- 鼠标悬停：挥手（已处理原 GIF 的白边）。

Codex 控制各状态的触发和播放节奏；本素材不能保证处理动作在整个任务期间持续循环，也没有实现处理动作的 8:2 随机选择或每次显示时播放一次开场动画。部分原素材只有上半身、分辨率较低，动作切换可能出现尺寸或姿势变化。
